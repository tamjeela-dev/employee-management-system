# Employee Management System

A simple Employee Management System built with Vue.js 3, Vue Router, Axios, and Bootstrap.

## Features

- Dashboard
- Employee List
- Add Employee
- Edit Employee
- Delete Employee
- Search by Name
- Search by Email
- Search by Gender
- Responsive UI

## Technologies Used

- Vue.js 3
- Vue Router
- Axios
- Bootstrap 5
- JavaScript (ES6+)
- HTML5
- CSS3

## Installation

```bash
npm install
npm run dev
```
