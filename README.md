# Employee Management System

A simple Employee Management System built with **Vue.js 3**, **Vue Router**, **Axios**, and **Bootstrap**.

## Features

- Authentication (Login)
- Route Guards (Protected Routes)
- Dashboard
- Employee List
- Add Employee
- Edit Employee
- Delete Employee
- Delete Confirmation
- Search by Name
- Search by Email
- Search by Gender
- Form Validation
- Loading States
- Error Handling
- 404 Page Not Found

## Technologies Used

- Vue.js 3
- Vue Router
- Axios
- Bootstrap 5
- DummyJSON API
- JavaScript (ES6)
- HTML5
- CSS3

## Project Setup

```bash
npm install
```

### Run Development Server

```bash
npm run serve
```

or (if using Vite)

```bash
npm run dev
```
